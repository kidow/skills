# MS Paint Scribble

A photo redrawn as a deliberately bad, scribbly mouse drawing in MS Paint, with jagged pixel lines and messy fills on white.

## Prompt

```text
Redraw the attached image in the most clumsy, scribbly, and utterly pathetic way possible. Use a white background, and make it look like it was drawn in MS Paint with a mouse. It should be vaguely similar but also not really, kind of matching but also off in a confusing, awkward way, with that low-quality pixel-by-pixel feel that really emphasizes how ridiculously bad it is. Actually, you know what, whatever, just draw it however you want.

Don't include any text, letters, or logos.

Keep the same aspect ratio as the attached image.
```

## Observed in references

These traits come from the example image on the user's linked prompt page. The image wasn't stored. Add the ones you want to the image prompt.

- **Fills:** colors are filled with fast, overlapping zigzag scribbles rather than the paint bucket, leaving white gaps.
- **Lines:** outlines are thin, wobbly, aliased black mouse strokes.
- **Detail:** important features, such as eyes, get small bright accents, while the rest stays rough.
- **Background:** the background stays plain white, with small objects scattered around the main subject.
- **Text:** the example is a movie poster with scribbled title lettering, which this style leaves out.
- **Overlap:** `crayon-kid-drawing` uses waxy crayon texture on paper, while this style uses thin digital pixel lines on a white screen.
